Cómo usar este brand kit

— 01

Servidor local

Levanta un servidor desde la raíz del repo para que las fuentes y rutas relativas resuelvan correctamente.

python3 -m http.server 8000

— 02

CSS = fuente única

Todos los archivos cargan styles/site.css — si cambias un token ahí, todos los previews se actualizan solos.

— 03

Hover e interacciones

Los previews son HTML funcional — abre en browser para ver estados hover, animaciones y comportamiento de formularios.

— 04

README como spec

El README.md de la raíz es la especificación canónica. En caso de conflicto entre spec y CSS, gana el CSS.
