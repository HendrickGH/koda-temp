Qué medimos y cómo.

Este benchmark se basa en mediciones públicas (Chrome User Experience Report, datos de Google Lighthouse) y datos privados de 40+ proyectos B2B mexicanos auditados entre Q4 2025 y Q1 2026. Métricas reportadas:

  • LCP (Largest Contentful Paint): tiempo hasta que aparece el elemento más grande visible. Google penaliza sitios > 2.5s.
  • CLS (Cumulative Layout Shift): qué tanto se mueve el layout durante carga. Ideal < 0.1.
  • INP (Interaction to Next Paint): tiempo de respuesta a interacciones. Ideal < 200ms.
  • Tasa de conversión: visitantes que ejecutan la acción objetivo (lead, descarga, registro).
  • Bounce rate: porcentaje que sale sin interactuar. Engañoso si se mira aislado.

La diferencia que hace el código a medida.

Las medianas del benchmark se ven feas porque incluyen sitios en WordPress + Elementor, Wix, GoDaddy templates y otros constructores que arrastran legacy de plugins. Los sitios construidos con stack moderno y código a medida (Next.js, Astro, frameworks similares) muestran otra realidad:

Métrica WordPress promedio Código a medida
LCP 4.3s 1.6s
CLS 0.19 0.03
Bundle JS 1.2 MB 180 KB
Lighthouse Performance 54 96
SEO Score 78 100

Cómo auditar tu propio sitio.

  1. PageSpeed Insights de Google (pagespeed.web.dev): métricas reales de tu sitio. Si estás bajo 60 en mobile, urge intervención.
  2. Chrome DevTools / Lighthouse: análisis local más detallado para identificar exactamente qué pesa más en la carga.
  3. Google Search Console — Core Web Vitals: datos reales de usuarios reales (no laboratorio).
  4. Comparativa contra competidores: mide los 5 sitios más relevantes de tu sector con la misma herramienta. Ahí verás si tu mediocridad es relativa o absoluta.

Próximos pasos si estás bajo el promedio.

Hay tres caminos posibles según tu situación:

  • Optimización sobre el sitio actual (si está en código moderno con problemas puntuales): 1-3 semanas, $15K-$40K MXN. Aplica si tu sitio fue construido recientemente con stack adecuado.
  • Rediseño parcial (si el problema es de arquitectura pero el contenido funciona): 4-6 semanas, $40K-$80K MXN. Aplica para sitios con buena estructura pero implementación pobre.
  • Reconstrucción completa (si está en WordPress + plugins con deuda técnica): 6-10 semanas, $60K-$150K MXN. Aplica cuando el sitio ya no es salvable.
